# Fútbol Plus Ultra - Proyecto Web

Este proyecto contiene los archivos necesarios para la página web de Fútbol Plus Ultra con integración de noticias dinámicas vía `news.json` y vídeos vía `videos.json`.

## Estructura de archivos:
- `index.html`: Página principal.
- `noticia.html`: Vista de detalle de noticia.
- `news.json`: Archivo de datos de noticias (actualizado por Make/GitHub).
- `videos.json`: Archivo de datos de vídeos.
- `assets/`: Carpeta para imágenes (logo, banner, etc.).
